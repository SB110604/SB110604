  • Click Add custom domain

5
Configure DNS in Namecheap
Add TXT, A records and CNAME in Namecheap Advanced DNS so the domain points to Firebase
namecheap.com → Domain List → Manage → Advanced DNS

  • Log in to namecheap.com → Domain List → click Manage next to sahilbodke.xyz
  • Click the Advanced DNS tab at the top
  • Delete any existing default A or CNAME records Namecheap added (URL redirect / parking records) — they will conflict
  • Add a TXT record: Host = @, Value = the token shown in Firebase Console (starts with firebase=)
  • Go back to Firebase Console and click Verify — wait a few minutes if it does not verify immediately
  • After verification, add two A records: Host = @, Values = the two IPs shown in Firebase Console
  • Add a CNAME record: Host = www, Value = portfolio.web.app. (include the trailing dot)
  • Click Save all changes
Important: Use the exact IP addresses shown in your Firebase Console — they differ per project. Do not copy IP addresses from tutorials or examples.
